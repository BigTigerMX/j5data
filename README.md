# J5 Data — Sitio web corporativo

Sitio web de **J5 Data Services**: infraestructura de red de misión crítica para el sector público y privado. Ingenieros certificados CCIE, +20 años de experiencia, tecnología Cisco. CDMX, México.

**Concepto de diseño:** *"La Red Viva"* — topología de red animada y estética de Centro de Operaciones (NOC).

## Stack
Sitio estático, sin dependencias ni build:
- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js` (vanilla, canvas + IntersectionObserver, respeta `prefers-reduced-motion`)
- `assets/img/` — imágenes WebP

**Tipografías:** Zodiak + General Sans (Fontshare) · JetBrains Mono (Google Fonts).

## Ver localmente
Abrir `index.html` en el navegador, o servir con:

```bash
python -m http.server 8000
```
